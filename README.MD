# PAK Car Plate Number Decoder

A simple Python application that decodes Pakistani vehicle registration numbers based on their city/province prefixes.

## Features

- Decode Pakistani number plates
- Validate plate format
- Identify city and province
- Modular project structure
- Beginner-friendly code

## Example

Input:

LHR-1234

Output:

City: Lahore
Province: Punjab
Registration Number: 1234

## Run

```bash
python main.py
```
